# 随缘网｜移动端适配与手机验收 V1.0

更新时间：2026-10-10。分支：`feat/mobile-ux-responsive`（基于 `refactor/standalone-suiyuan`）。本版本仅修改独立站前端及测试保护，不改变线上服务、数据库或正式会员资料。

## 使用上的改进

| 场景 | 手机端交互 |
|---|---|
| 顶部 | 缩小品牌导航，增加固定“更多”入口，覆盖兴趣筛选、同城、社区、收藏、成长、安全说明及管理入口。面板可关闭并保留焦点管理。 |
| 底部 | 登录后四个常用标签：推荐、活动、消息、我的；增大图标和触控高度，支持刘海屏底部安全区域。打开会话或输入软键盘时避让。 |
| 聊天 | 手机从会话列表进入全屏会话，可在顶部返回；`/matches?with=...` 支持深链接和浏览器返回。消息内容自适应宽度，输入框 16px、发送按钮大尺寸，快捷回复折叠，不自动用键盘回车发送（避免中文输入法误发）。 |
| 注册 | 原本独立按钮提交改为表单提交；邮箱使用移动键盘/email 自动填充，16px 输入尺寸，成年人确认复选框更易点。 |
| 资料 | “基本资料／照片／账号与隐私”快捷入口；更适合手机的头像高度，防止首页大量滚动。 |
| 活动 | 筛选条可水平滑动，触控目标不小于 44px，兼容小屏。 |
| 弹窗 | 小屏底部弹层、可滚动内容、可点击关闭区，并保留 Esc/焦点回收；支持底部安全区。 |
| 首页 | 单列主要 CTA、减小主标题字号和首屏上下留白，更适合单手点击。 |
| 系统基础 | `viewport-fit=cover`、`100dvh` 自适应、焦点可见、降低动画选项，避免输入框触发 iOS 浏览器缩放。 |

保持原有中式红/米金视觉风格；桌面及平板布局继续由 Tailwind 断点控制。

## 添加到手机主屏幕

本版添加了同源 `/manifest.webmanifest`、192/512px 本地 PNG 图标和 iOS 主屏幕元数据。
用户在 **网站可访问的 HTTPS 地址** 打开后：

- iPhone：Safari 分享菜单 → “添加到主屏幕”。
- Android：Chrome 菜单 → “安装应用”（如浏览器支持）或“添加到主屏幕”。
- 添加后可从手机主屏幕点随缘网图标进入。**这仍是网站，不是原生 iOS/Android 安装包。**

本版**不添加 Service Worker**，避免缓存聊天记录、用户照片、鉴权接口等敏感数据，因此不承诺离线可用、推送通知或后台收信。某些浏览器可能不提供一键“安装”按钮，但一般仍有收藏或创建主屏幕快捷方式功能。

## 自动化验收与安全边界

```bash
pnpm install --frozen-lockfile
pnpm lint
pnpm test
pnpm build
pnpm standalone:check
pnpm mobile:check
```

- `pnpm mobile:check` 使用 Chromium + **全量合成 API mock**，在本地回环地址测试 320×568、375×812、390×844、430×932、768×1024。覆盖游客登录页、主屏幕入口、导航、会员会话列表、聊天切换、快捷回复、资料快捷操作和活动页，检查横向溢出及页面异常。**不会连接、写入或清空 Neon 数据库。**
- `pnpm e2e` 是真实数据库读写的集成测试，`scripts/e2e-run.mjs` 和 `e2e/global-setup.mjs` 均强制检查数据库名与专用 Staging 角色；必须提供已获授权的 `suiyuan_staging` 凭据，并仅在自动创建/销毁的 `e2e_smoke_*` schema 内执行。**不可使用本机来源不明的 dev-secrets.local。**
- 模拟触屏不等于真实 iPhone Safari / Android Chrome，软键盘、返回手势、底部安全区仍需实体手机复测。
- 在国内免 VPN 访问方面，应用前端适配不会改变 Vercel/Render 跨境域名可能不通的问题。公网入口仍需独立选型及大陆网络实测。

## 建议的实体设备复测项

1. iPhone Safari 与 Android Chrome 分别用 320–430px 视口的真机打开测试站。
2. 游客：首页、登录、注册、成年人确认及协议页面，尝试安装主屏幕快捷方式。
3. 测试账号：主导航、更多菜单、头像与照片、我的资料保存/返回提醒。
4. 有真实互配的合成测试账号：消息列表 → 进入会话 → 键盘输入/中文输入法组词/发送/返回 → 再次进入；确保底部按钮可见、会话不会滚出视口。
5. 活动筛选/活动详情/创建表单；资料弹层打开关闭与焦点恢复。
6. 低速移动网下重试和无网络态；Render 免费模式禁止真实用户上传图片。

## 发布

只推送 `feat/mobile-ux-responsive` 独立分支，不把代码自动合并到 main、现有 Vercel/Render Staging。迁移公网前再检查 SSL、账户安全、跨境链路、持久图片存储及成年人平台合规要求。
