# 12 发布与回退手册（含发布记录）

## 发布流程（每次发布三步）

1. **冒烟**：`NEON_DSN='postgresql://…' pnpm e2e` —— 7 例全过才继续（隔离环境自动建销，不碰生产）。
2. **三道闸**：`pnpm lint`（0 error）、`pnpm test`（全绿）、`pnpm build`（成功）。
3. **健康抽查**：数据网关健康检查、页面服务 200、抽一条业务数据核对（如动态条数）。

三步全绿即视为可发布；本环境为容器内常驻服务，代码合入本地主干并重启网关即完成上线。

## 回退与恢复

- **回退到旧数据服务**：停数据网关 → 进程管理器启动旧数据服务进程。代价：丢失切换后新写入的数据，仅作故障兜底（见 11）。
- **容器重启后恢复**：连接串不落盘（安全约定），重启后需重新拉起网关：运行启动脚本按提示粘贴连接串，或以环境变量方式启动。切换当日实测恢复耗时约 1 分钟。
- **数据库层回退**：Neon 控制台 PITR / 分支（建议开启，见 11）。
- **备份演练**：`NEON_DSN='postgresql://…' node scripts/neon-backup-drill.mjs` —— 生产只读导出全量 → 装入一次性隔离空间 → 逐表核对行数与内容指纹 → 销毁。2026-09-22 首跑通过（22 表 / 58 行全一致）。
  注意：Neon 连接池为事务模式，会话级 `set search_path` 会跨连接泄漏；本仓所有脚本一律事务级设置 + 全限定表名。

## v1.4 发布记录（2026-09-23）

**内容**：限流与登录防爆破（09 残留项 3 部分清账）。

- 网关内置内存固定窗口限流：全局单 IP 1200 次/分、登录接口单 IP 60 次/10 分、注册单 IP 20 次/时，超限 429（健康检查不计入）
- 登录防爆破：同一邮箱连续错 8 次密码锁 15 分钟，锁定期在密码校验前判定（正确密码也拒）；成功登录清零计数；按邮箱隔离不误伤他人
- 登录页透出 429 的具体提示（如「请 X 分钟后再试」），其余错误保持产品语兜底
- 客户端 IP 取 X-Forwarded-For 第一跳（代理部署形态），无该头时退回套接字地址

**验证**：发布冒烟 7/7（新增防爆破断言组：连续 8 次错密码后正确密码被 429、锁定按邮箱隔离、持 token 的清理不受锁定影响）；三道闸全绿；线上健康抽查见发布时记录。

**回退**：纯网关 + 界面代码变更，无数据迁移。限流为单进程内存语义，重启即清零（发布/回退天然重置限流状态）。

## v1.3 发布记录（2026-09-23）

**内容**：输入尺寸护栏（服务端字段级校验 + 界面 maxLength 配套）。

- 网关对全部业务写路径（建 / 改）加字段级尺寸校验：文本按字符数（如动态正文 ≤5000、留言 ≤1000、名片 ≤200、昵称 ≤30）、数组按元素数（如配图 ≤9、兴趣 ≤17），超限返回字段级 400；图片 dataURL 只限张数，字节数由既有 25MB 请求体上限兜底
- 界面各输入框补齐 maxLength（发帖 / 私信 / 回帖 / 活动留言 / 资料 / 活动表单 / 举报 / 报名联系方式），与服务端上限一致，正常操作永远不会触到服务端拒绝
- 上限取值先经生产只读盘点（现有数据最长字段远低于上限，护栏不影响存量数据的同步写回）

**验证**：发布冒烟 6/6（新增尺寸护栏断言组：超长正文 400 字段级报错、超量配图 400、正常尺寸 200）；三道闸全绿；线上健康抽查见发布时记录。

**回退**：纯网关 + 界面代码变更，无数据迁移；还原代码并重启即回退。

## v1.2 发布记录（2026-09-23）

**内容**：满员校验服务端化 + 跨行读收紧（09 残留项 2、4 清账）。

- 活动报名建行时网关在同一事务内对活动行加锁（for update）后计数校验，超员返回字段级 400「活动已满员」；此前校验只在客户端，直连接口可超员报名
- checkins / contacts 的列表与单行读收紧为「本人行 + 自己发起的活动下的行 + 掌柜」：名片含联系方式、签到含行踪，此前任意登录成员可读全表
- checkins 写侧收紧：建 / 改仅本人行（此前任意登录成员可写他人签到行）
- 报名幂等保留：本人已有报名行时重复提交返回已存在记录，不算新增名额

**验证**：发布冒烟 5/5（新增断言组：满员第三人被 400 拦截、退订后名额释放、幂等重报 200、无关成员列表不见他人名片 / 签到、发起人可见、冒充写名片 / 签到 403）；三道闸全绿（lint 0 error、单测 3 文件 / 20 例、构建成功）；线上健康抽查见发布时记录。

**回退**：纯网关代码变更，无数据迁移。回退 = 还原网关代码并重启；已写入数据与新规则完全兼容。
