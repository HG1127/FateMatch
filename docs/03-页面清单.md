## 主流程

1. **进入闭环**：访客看首页 → 注册 → 建档（我的-资料）→ 认证提升可信度 → 进入缘分推荐。
2. **配对闭环**：缘分 / 探索 / 附近产生心动 → 双方互心动 → 出现在 mutual 消息 → 私聊 → 交换联系方式（contacts）。
3. **线下闭环**：活动报名 → 活动当日签到 → 活动留言 → 社区发帖回顾 → 每周精选收录。
4. **运营闭环**：举报 / 巡查 → 后台安全页签处置（封禁 / 下架）→ 运营日志留痕 → 数据维护页签盘点与备份。

## 变更规则

新增 / 下线页面必须同步更新本表与路由；受开关保护的页面在开关关闭时对会员显示提示页而非 404。
