## 关系

- Account 1—1 Profile（账号 id 即会员 sid）。
- Profile 1—N Post / PostComment / EventComment / Favorite / Visit / Report / Contact。
- Post 1—N PostComment；Post N—N Digest（经收录名单）。
- Event 1—N EventComment / Checkin / Reminder；报名名单存于活动内。
- Like / Pass / Read / Block / Visit 为**关系表**：两端都是会员 sid。
- ChatMessage 属于会话（sid_a, sid_b 无序对）。

## 不变量（仓储层护栏）

1. **业务主键与存储 id 分离**：跨端引用一律用 sid；存储层 id 不外泄到业务逻辑。
2. **差量同步**：世界快照整载（loadWorld）→ 本地修改 → 差量写回（syncWorld：增 / 改 / 删三类）。
3. **删除护栏**：私有表只允许删本账号行；公共表若待删缺失比例 > 25% 视为快照过期，放弃删除防误清。
4. **隐私语义**：隐身会员不出现在走访与被推荐；封禁会员对会员端隐藏、后台可见。
5. **互配才可见聊天**：会话仅在双方互心动后建立；消息仅会话双方与掌柜可读（服务端规则）。
6. **审计**：后台处置动作写运营日志；日志仅掌柜可读。
