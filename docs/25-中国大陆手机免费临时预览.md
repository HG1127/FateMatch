# 随缘网｜中国大陆手机临时预览方案

2026-10-10，代码分支 feat/china-mobile-preview（基于已通过验证的 feat/mobile-ux-responsive）。
本方案**没有迁移、复制或写入正式会员数据库**，不改动当前线上 Vercel/Render、正式 Git main。使用构建完成的 React 手机版和受密码保护的本机 Node 服务。当前 Windows 已实测 Render HTTPS 握手超时，因此以**本机 Node API + 独立 Neon Staging** 为优先方案，原 Render 代理仅用于诊断。Neon 从中国大陆是否可连通仍须在本机配置专用测试连接串后验证。

## 适用范围与限制

- 技术验收：手机浏览器访问独立手机版 React，预览访问密码与测试会员账号分离。**优先运行 `china:preview:local`：前端端口 8611，同源 API 受控代理本机 8622 的 Node 服务，其数据库强制只能是 `suiyuan_staging` + `staging_render_preview`。** 不会从用户本机其他生产连接配置继承数据库密码。
- 免费试验：Cloudflare Quick Tunnel（现有 Windows 已安装其客户端）或 cpolar Free。两者**不保证**中国大陆每个运营商免 VPN 可达。需要在国内关闭 VPN 用移动数据验证。
- cpolar 免费版为随机 HTTPS 域名、约 1Mbps，隧道地址会更换。Windows 电脑、网关和隧道进程必须在线。免费版不适合真实会员试运营。
- **禁止真人资料、真实会员照片、银行卡/手机号、真实姓名、证件等。** 本地网关拦截 /api/uploads 写入；正式照片永久存储尚未解决。
- 不使用 Service Worker，避免自动缓存敏感聊天/资料；手机添加主屏幕仅为网页快捷入口，不是已审核的 App。

## 一、独立 Neon Staging 本机后端＋受口令保护的移动站

先确保 Git 分支是 feat/china-mobile-preview：

    git switch feat/china-mobile-preview
    pnpm install --frozen-lockfile
    pnpm build

**首次使用必须在自己的 Windows 电脑配置专用 Staging 数据库：**打开 https://console.neon.tech，进入新建的 `suiyuan-staging` 项目，Branch 选 `staging`，Database 选 `suiyuan_staging`，Role 选 `suiyuan_staging_owner`，复制 Connection string。使用记事本打开项目根目录 `china-staging.example`，把示例 `NEON_DSN` 替换成真实连接串，另存为 `D:\Downloads\随缘网\china-staging.local`。它通过 `*.local` 自动被 Git 忽略；**不要发送给 ChatGPT、不上传到 GitHub、不从旧的 dev-secrets.local 复制生产库连接串。**

此文件必须保留下面两行：

    NEON_SCHEMA=staging_render_preview
    STAGING_MODE=1

随后启动：

    pnpm china:preview:local

脚本会在开放任何预览端口前验证数据库角色、库名、Neon 域名和 schema，然后只启动本地 127.0.0.1:8622 API、127.0.0.1:8611 前端受保护入口。必须等 `/api/ready` 返回 200 才开放前端；75 秒内数据库不可达则安全失败，不会公开半可用的登录页面或错误地回退到生产数据库。数据库串永不进入浏览器、Git 或日志。图片上传仍被阻止。

旧版 `pnpm china:preview` 只启动受口令前端并代理到 Render，新加坡 HTTPS 已在当前 Windows 网络实测连接超时，不推荐作为中国大陆功能验收入口。

首次运行自动在项目根目录建立**已被 Git 忽略**的 china-preview.local。文件含随机生成的访问口令和 Cookie 签名密钥，**只保留在本机、不要分享到 ChatGPT 或 GitHub**。如果需要查看口令，可在 Windows 文件资源管理器打开 D:\Downloads\随缘网\china-preview.local，只复制 accessPassword 的值。

本机探针：

    http://127.0.0.1:8611/_preview/health

本机网页未登录会转向受口令保护的 /_preview/login；登录成功后经 HTTPS 发放 HttpOnly+Secure Cookie，8 小时过期。**请使用公网 HTTPS 隧道网址输入口令，避免通过普通 HTTP 输入访问口令。**

## 二、Cloudflare Quick Tunnel 检查结果（当前网络不适用）

已实际执行过以下命令，但向 api.trycloudflare.com 请求临时地址时超时，并**未获得任何可用公网 URL**，所以不建议反复尝试：

    cloudflared tunnel --no-autoupdate --url http://127.0.0.1:8611

客户端输出类似 https://xxxx.trycloudflare.com 的随机 URL。此链接有效仅限客户端进程运行期间，可能因网络和服务中断失效。用户用中国大陆 4G/5G 关闭 VPN 打开，看到随缘网自己的测试口令页后输入本机 china-preview.local 中的 accessPassword。

仅仅在海外网络打开不代表在大陆免 VPN 可用。当前电脑已验证 Cloudflare Quick Tunnel 申请失败，下一步走 cpolar Free；不要绕过口令防护公开 Vite 开发服务器。

## 三、优先作为中国大陆尝试的 cpolar Free 替代

cpolar 官方页面：https://www.cpolar.com/pricing
Windows 安装与配置：https://www.cpolar.com/docs

已从 cpolar 官网下载 Windows 64-bit 官方安装包到 `D:\Downloads\cpolar-official-windows-setup.zip`，解压后的文件为 `D:\Downloads\cpolar-official-extracted\cpolar_amd64.msi`，Windows 检查其 Authenticode 电子签名为 **Valid**、签名发布者 `Beijing Jiaxun Technology Co., Ltd.`。**软件尚未安装，也尚未关联你的 cpolar 账号**，需要你本人完成安装和平台登录/Token 认证。不要把 Token 发进聊天。操作：

1. 在 cpolar 官网选择 Free 免费套餐，注册并登录账号。运行上述已下载的官方签名 MSI 安装包；按官网说明在网页控制台中完成本机客户端 authtoken 认证（在本机操作，不要发到聊天）。
2. Windows 浏览器打开 http://localhost:9200（官方管理控制台）。
   **安全必做**：cpolar 在 Windows 安装后可能默认配置 remoteDesktop（3389）或 website（8080）样例隧道。先在「隧道列表」停用或删除这类默认隧道，绝不要意外公开远程桌面、SSH 或旧开发端口。
3. 确认本机 `pnpm china:preview:local` 已运行且就绪，然后选择「隧道管理」→「创建隧道」，隧道协议 `http`，本地地址只填 **8611**，域名类型为 `随机域名`，地区只选 Free 套餐允许的区域（官网明确 China NAS 区域限定 NAS 套餐，请勿为了选区购买付费套餐）。
4. 创建并在「在线隧道列表」复制 **https://** 开头的随机域名，在中国大陆手机关闭 VPN，使用 4G/5G 打开。输入独立预览访问口令；使用合成数据测试注册和消息。
5. 公网只允许映射 8611；**绝对不要映射 8622、9200、7000、7200、8000、8080、5432 或远程桌面 3389**，避免直接暴露没有前置测试口令的内部 API、数据库或管理端。

cpolar 自带认证、频率等功能按官方选项为准；我们已在应用入口实现单独访问口令，默认拒绝匿名访问。若 cpolar 管理界面支持关闭请求内容检查/历史记录，建议关掉，以免保存 Cookie、聊天或测试口令。不要公开 9200 管理界面。用户不能稳定共享免费随机域名，不能承诺永久在线。

## 四、无数据库写入验收

    pnpm china:preview:check   # 预览密码安全 + Staging 连接串防误用（本机假串，无真实 DB）
    pnpm mobile:check
    pnpm lint
    pnpm test
    pnpm build

china:preview:check 在随机本机端口模拟 Staging API，验证匿名请求被拒绝、网页登录后静态资源可用、浏览器 JWT 能透传而私密 Cookie 不泄漏，以及禁止测试图片上传。无需任何 Neon DSN。

## 五、发布闸门和长期计划

- China tunnel URL 不等于国内备案完成，也不能替代正式会员隐私安全方案。
- 真实 iOS Safari、Android Chrome 的软键盘、返回手势、快慢网、主屏幕快捷入口仍要在实机检验。
- 如果中国大陆公网长期稳定访问是正式目标：选择合法合规的国内托管、ICP备案域名、满足个人信息保护的业务基础设施，并把头像、照片等文件迁入持久安全对象存储。
- 下一次升级已部署 Staging 需要明确批准变更对应 Git 分支/版本，并实测服务。此分支不会自动更新 Vercel 或 Render。
