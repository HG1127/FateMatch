# 09 权限策略

## 角色

| 角色 | 判定 | 能力边界 |
| --- | --- | --- |
| 访客 | 未登录 | 官网首页、登录注册页；其余路由跳转登录 |
| 会员 | 登录账号（role 为空） | 功能开关开启的各模块；只能写自己的私有数据 |
| 掌柜 | 登录账号 role = admin | 会员全部能力 + 后台五个页签（含处置与数据维护） |

页面准入矩阵见 `03-页面清单.md`；功能开关（yuanfen / explore / events / community / matches）由掌柜在站点设置中调整，关闭时会员端显示统一提示页。

## 残留风险与计划

1. ~~**公共内容表 update 对成员开放**~~ **已解决（2026-09-23 计数拆分）**：点赞 / 报名名单拆到 content_likes / event_attendees 独立表（仅本人行可写），浏览计数改网关原子自增端点；posts / post_comments / events / event_comments 的 update 收紧到「作者 / 发起人 + 掌柜」，digests 收紧到「仅掌柜」。主表旧名单列保留但网关已屏蔽读写（回退兜底）。迁移：40 条点赞 + 16 条报名逐条核对一致。顺带修复两处界面与服务端不一致：评论作者删自己的评论、活动发起人删自己活动（此前服务端只认掌柜，非掌柜的删除会被静默拒绝、刷新后复现）。同时补上 profiles.role / banned 的字段级防护（此前成员理论上可通过改自己的资料行自我提权）。
2. ~~**checkins / contacts 读对成员开放**~~ **已解决（2026-09-23 v1.2）**：列表范围收紧为「本人行 + 自己发起的活动下的行 + 掌柜」（HOSTED 范围，子查询判定发起人）；单行读同语义（跨表函数规则）。名片联系方式不再对无关成员暴露，与界面「仅发起人可见」的展示语义对齐。写侧同步收紧：checkins 建 / 改仅本人行（此前任意成员可写他人签到行）。
3. **无公网限流** **部分解决（2026-09-23 v1.4）**：网关内置内存固定窗口限流——全局单 IP 1200 次/分、登录接口单 IP 60 次/10 分、注册单 IP 50 次/时（v1.8 由 20 上调：预览代理形态下全站可能共享出口 IP，需留足真实注册余量），超限返回 429；登录防爆破：同一邮箱连续错 8 次密码锁 15 分钟（锁定期正确密码也拒，按邮箱隔离不误伤他人）。单进程内存语义、重启清零，适配当前容器单实例部署；若接公网或多实例，需升级为网关/WAF 层限流与共享计数（如 Upstash）。
4. ~~**活动满员校验在客户端**~~ **已解决（2026-09-23 v1.2）**：报名建行时网关在同一事务内对活动行加锁（for update）后计数校验，超员返回字段级 400「活动已满员」；并发抢最后一个名额不会超员。本人已有报名行时幂等返回不算新增；退订后名额即时释放。已知边界：被服务端拒绝的报名在前端为静默失败（本地态到下次刷新才纠正），界面按钮本身有满员禁用，仅并发竞态时可见。
5. ~~**公开表 create 的归属冒充**~~ **已解决（2026-09-23 v1.7 服务端种子化）**：演示内容改由种子脚本一次性灌库（`scripts/seed-demo-data.mjs`，夹具只含种子用户署名行、经隐私核对），客户端同步对种子归属行跳过建行；posts / events / profiles / post_comments / event_comments 的 create 随即收紧到「本人署名（author_sid / creator_sid / sid = 我）+ 掌柜」，冒名发帖 / 建活动 / 写评论 / 占坑资料行全部 403。已知边界：私信 from_sid 仍可填对方（自动回复架构所需），但会话双方约束 + 拉黑拦截已在 v1.6 落地，风险面仅限伪造对方语气，界面上双方内容本就同源。

## 审计

- 后台处置动作写运营日志，日志仅掌柜可读可写。
- 数据盘点与备份导出仅后台入口提供；备份文件剥离会话签名密钥字段。
- 输入尺寸护栏（v1.3）：全部业务写路径经字段级校验（文本字符数 / 数组元素数上限，超限返回字段级 400），界面 maxLength 与之配套；防异常客户端写入超大内容拖垮全量同步。请求体字节数另有 25MB 上限兜底。

## 附件与会话生命周期（v1.8）

- **图片上传**：登录成员 `POST /api/uploads`（dataURL → 落盘 `uploads/`），返回不可猜测文件名；读取凭 URL 公开（`<img>` 无法带登录头），隐私边界 = 文件名不可枚举 + 仅登录成员可上传。数据库不再新增大体积 dataURL（存量 dataURL 仍可展示）。`uploads/` 不入 git，需随数据库一并做文件级备份（见 12）。
- **令牌生命周期**：令牌携带密码指纹（HMAC，不暴露哈希本体）；本人改密或掌柜重置后旧令牌即时 401，前端自动登出引导重登。存量旧令牌（无指纹）过渡期 ≤14 天自然到期，封禁校验不受影响。已注销账号的令牌按匿名处理。
- **注销级联**：删除账号在同一事务内清理——本人资料行、本人动态及其下全部评论、本人发起的活动及附属数据（报名 / 签到 / 名片 / 留言）、本人点赞（含落在本人内容上的他人点赞）、全部私密行（收藏 / 分组 / 拉黑 / 提醒 / 已读 / 跳过 / 心动 / 引导 / 举报 / 本人走访）、账号行。**保留**他人拥有的行：对方侧的会话消息（双方共有记录）、他人对我的点赞 / 拉黑 / 走访——界面按「已注销会员」渲染。
