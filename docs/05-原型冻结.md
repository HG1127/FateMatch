# 05 原型冻结

## 冻结点

2026-09-08。自此 UI 基线冻结，进入工程化阶段；此前的多轮迭代视为原型期（07 / 08 步）。

## 基线内容

- **页面基线**：`03-页面清单.md` 所列 16 条路由。
- **视觉基线**：现行设计令牌（朱印红 + 宣纸底 + 行楷标题字）与组件样式；改视觉须先改令牌再改组件，不允许单页硬改色值。
- **交互基线**：五个功能开关（yuanfen / explore / events / community / matches）默认全开；开关关闭显示统一提示页。
- **数据基线**：22 张业务表结构见 `08-数据Schema与迁移.md`；冻结后改表走迁移流程。

## 冻结后的变更规则

1. 新增 / 下线页面：先更新 03 页面清单，再写代码。
2. 改表结构：先备份，再按 08 迁移流程执行，并同步仓储层与盘点清单。
3. 视觉改版：以「换风格」形式整体迁移令牌，不做局部漂移。
4. 任何变更过三道闸（lint / build / test）后才可进入主干。
