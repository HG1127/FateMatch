# 随缘网：关系反馈试点验收与发布清单

核查日期：2026-10-08

## 1. 完成范围与边界
- 会话成员在互相有意、且至少存在一条未撤回的真实聊天消息后，可自行选择“愿意继续认识”或“先暂停认识”。
- 一位用户针对一位对象只保存一个**当前值**（`continue` / `pause`）；可以改选，也可以传 `null` 撤回。不收自由文本、不留选择历史、不告知对方。
- 关系反馈不等于拉黑、取消互配、断开会话或调整推荐。它仅是试点结果信号，必须经本人主动操作。
- 前端仅在聊天详情按需加载反馈，不扩大登录首包。

## 2. 权限契约
| 操作 | 权限及返回 | 校验 |
| --- | --- | --- |
| `GET /api/me/relationship-feedback/:otherSid` | 仅本人读取自己对该对象的 `{available,eligible,outcome}` | 匿名拒绝；不会返回对方意见 |
| `PUT /api/me/relationship-feedback/:otherSid` | 仅本人提交 `{outcome:"continue"|"pause"|null}` | 除撤回外，必须互配且有真实消息；其他值拒绝 |
| `/api/collections/relationship_feedback/records` | 对所有身份不开放 | 404，不允许枚举原始反馈 |
| `GET /api/admin/pilot-metrics?days=7` | 仅掌柜看继续/暂停聚合数 | 排除演示、管理员和停用账号，不返回逐人关系 |

- 反馈表：`relationship_feedback`。列包括 `id/owner_sid/other_sid/outcome/at/created/updated`；主键、`(owner_sid,other_sid)` 唯一索引、`updated` 索引和 `outcome` 限制约束已核实。
- 注销时清理涉及该账号的反馈（属主或对象），与既有账号级数据生命周期衔接。
- 掌柜指标为观察窗口内**最后一次更新发生于窗口内的当前选择数**；不是累计点击次数，也不是全部历史反馈量。
