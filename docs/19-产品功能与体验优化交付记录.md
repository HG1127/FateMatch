# 随缘网｜产品功能与使用体验深度优化交付记录

日期：2026-10-09
状态：**本轮代码和测试已完成验收；最终版本以 Git 提交记录为准，尚未部署正式网站**。正式上线前仍应在预发布环境重新验收。

## 一、核心目标与边界

以真实成人交友和线下活动为中心，减少新手阻碍、推荐不透明、聊天草稿丢失和活动信息不充分的问题。继续遵守：不模拟真人喜欢、已读或答复；不假冒第三方身份核验；活动、聊天、举报以服务端真实记录为准。保留原 VibeX App ID、路由和 React + TypeScript / Node + Neon 架构。

## 二、本轮功能改动

1. **发现与筛选**：兴趣筛选页提供可选的 18–100 岁年龄上下界。服务端校验输入并在候选查询和总数计算上同步过滤；年龄门槛不削弱既有成年人、互相寻找对象、拉黑和跳过资格。未接入的三项核验筛选明确禁用，以免空结果误导用户。
2. **同城体验**：同城页自主服务端加载同城候选、分页和失败重试；城市/登录账户切换自动重置本页候选，明确区分“真实总人数”和“当前已加载人数”。同城活动查询增加服务端城市参数，避免在客户端全城数据池中截断本地活动。
3. **新人引导**：资料编辑与必要推荐资格解耦，兴趣可后补；“我的”页将基础资料和照片前置，并提供直接跳转的必要资料入口。
4. **关系状态**：消息页明确展示本人已经表达但对方未互配的“待回应”选择，不猜测对方已读或意愿；卡片可查看并撤回本人选择。可搜索互配昵称、筛选未读会话。
5. **消息可靠性**：在用户浏览网站、标签页恢复前台时请求服务端会话摘要以刷新未读数字；这是**前台轮询**，不是推送通知。每个账户/会话的文本草稿以 sessionStorage 暂存，并限定过期时间；发送确认成功才清理。移动端聊天框支持多行及 Enter/Shift+Enter，不会因使用破冰建议覆盖原有草稿。
6. **社区体验**：发帖草稿在当前标签页保留文字与话题，不缓存图片；本人可编辑自己发布的帖子正文，失败不会假装修改成功；他人不可编辑。保留原有审核和敏感词规则。
7. **线下活动**：新增公开集合区域、费用说明和取消/改期规则字段，并真实贯通页面 DTO、写入与表结构；新活动要求填写集合区域及费用说明，旧活动保留原样并明确标注信息缺失。支持服务器端同城活动过滤；避免宣传平台代收款。
8. **移动端**：相册操作按钮在手机上可见，并提供前后移动排序键，无需拖拽。人物卡无照片时显示明确状态。
9. **无障碍和透明度**：弹窗支持 Esc 关闭最上层、焦点恢复和 Tab 焦点范围限制；活动卡与会话入口可用键盘进入；登录保留跳转来源、支持查看输入密码；移除后台关于“本地即时自动保存”的误导性说明。

## 三、数据结构改动（生产必须单独审批）

- `events.venue`（文本，公开集合区域）
- `events.cost_note`（文本，费用说明）
- `events.cancel_note`（文本，取消/改期说明）

已补入 `scripts/neon-schema.sql`（新库）及 `scripts/neon-migrations.sql`（存量库的幂等 ADD COLUMN）。**本轮没有对 public 生产数据库执行迁移，也没有写入真实用户或活动数据。**
预发布/上线前先确认目标 schema、做好数据库+附件同周期备份，测试环境验证后再执行受控迁移。

## 四、验收与限制

- 项目质量命令：`pnpm lint`、`pnpm test`、`pnpm build`、`pnpm e2e`。
- 新增回归覆盖：年龄偏好服务端过滤与无效参数拒绝、账户隔离会话文本草稿、编辑资料不强制兴趣、活动费用与集合区域、弹窗顶层 Esc、本人帖子编辑失败不覆盖、活动 DTO。
- 本轮**没有**外接短信/实名/照片核验厂商，也没有落地自动找回密码邮件、操作系统推送/短信提醒、AI 恋爱建议或付费业务。相应能力需平台外部服务及单独安全验收，禁止虚构验证成功或消息推送。
