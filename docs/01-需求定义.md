# 01 需求定义

## 产品一句话

随缘网：面向认真交往的单身人群的轻量婚恋社区，覆盖「认识 → 了解 → 线下见面」的完整闭环，数据自托管、可随时导出。

## 用户与场景

| 角色 | 场景 |
| --- | --- |
| 单身会员 | 注册建档 → 浏览推荐（缘分卡片 / 探索 / 附近）→ 表达意向（心动 / 跳过 / 走访 / 收藏）→ 私聊 → 社区发帖互动 → 报名线下活动并签到 → 做认证、攒勋章 |
| 掌柜（管理员） | 后台看运营总览 → 管理内容与成员（精选 / 置顶 / 封禁）→ 开关功能 → 维护站点设置 → 数据盘点与备份导出 → 处理举报 |
| 访客 | 看官网首页了解产品，进入注册 |

## 目标

1. 一个自托管应用内完成婚恋社交主闭环，不依赖外部 SaaS。
2. 信任体系可用：实名认证等级、勋章、举报与拉黑。
3. 运营可控：功能开关、内容治理、数据备份一键可得。
4. 工程可维护：分层清晰、有测试、有审查、有版本管理。

| 收藏 | 收藏会员与分组 | — |

| 安全 | 举报、拉黑 | — |

## 非目标

- 不做支付与会员付费墙。
- 不做原生移动端 App（Web 优先）。
- 不做 IM 级实时长连接（消息采用轮询）。
- 不做对接公网实名 / 征信数据源（认证为人工 / 凭证式）。
